# 🛒 Ordrly — The OG Order Management Website

> A full-stack order management platform where customers can place orders and vendors can create products and fulfill orders.

---

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:
- [Node.js](https://nodejs.org/) & npm
- [Bun](https://bun.sh/)

---

## ⚙️ Setup

### 🖥️ Frontend

```bash
cd app/frontend
npm install
npm run dev
```

### 🔧 Backend

```bash
cd app/backend
bun install
bun index.ts
```

---

## ✨ Features

- 🛍️ **Customer** — Browse and place orders
- 📦 **Vendor** — Create products and fulfill orders

---
